# TechTrack Frontend - Быстрый старт

## 🚀 Запуск проекта за 3 шага

### 1. Установите зависимости

```bash
cd techtrack-frontend
npm install
```

### 2. Создайте файл `.env.local`

```bash
echo "NEXT_PUBLIC_API_URL=http://localhost:8080" > .env.local
```

### 3. Запустите проект

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## ✨ Что дальше?

1. **Зарегистрируйтесь** - Создайте новый аккаунт на `/register`
2. **Войдите** - Используйте свои учетные данные на `/login`
3. **Изучите интерфейс** - Перейдите в дашборд `/dashboard`

## 📋 Основные страницы

- `/` - Главная (автоматический редирект)
- `/login` - Вход в систему
- `/register` - Регистрация
- `/dashboard` - Панель управления техникой
- `/equipment/[id]/issues` - Список неисправностей
- `/equipment/[id]/maintenance` - Журнал ТО

## 🛠️ Технологии

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State**: Zustand
- **Data Fetching**: React Query (TanStack Query)
- **HTTP Client**: Axios
- **Icons**: Lucide React

## 📝 Примечания

- Backend должен работать на порту 8080
- Убедитесь, что CORS настроен на бэкенде
- Первый пользователь должен создать компанию через API
- Роли и права доступа управляются на бэкенде

## 🐛 Решение проблем

**Проблема**: Не удается войти  
**Решение**: Проверьте, что бэкенд запущен и доступен на указанном URL

**Проблема**: Нет компании после входа  
**Решение**: Создайте компанию через API или назначьте пользователю существующую

**Проблема**: Ошибки CORS  
**Решение**: Настройте CORS на бэкенде, добавьте `http://localhost:3000` в allowed origins
