# TechTrack

## О проекте

TechTrack — это веб-сервис, предназначенный для учета оборудования, регистрации неисправностей, планирования технического обслуживания и уведомления сотрудников о важных событиях.

Проект разработан в рамках выпускной квалификационной работы п призван заполнить нишу, образовавшуюся на рынке после ухода зарубежных компаний.

## Основная функциональность

- Авторизация и аутентификация пользователей (JWT)
- Управление отделами организации
- Управление оборудованием
- Регистрация и управление неисправностями
- Планирование и управление техническим обслуживанием
- Ведение журнала технического обслуживания
- Система уведомлений
- Разграничение прав доступа

**Возможности**

### Структура предметной области

<p align="center">
  <img width="402" height="521" alt="image" src="https://github.com/user-attachments/assets/0920dad6-e1b0-4f51-96c4-c0c87b254224" />

Иерархия данных системы: Компания → Отделы → Оборудование.
Каждая единица оборудования имеет текущее состояние, журнал технического обслуживания, может иметь активные неисправности и запланированные обслуживания.


```
Компания
    └── Отдел
            └── Оборудование
                    ├── Неисправности
                    └── Техническое обслуживание
```

Каждый объект оборудования хранит:

- текущее состояние;
- историю технического обслуживания;
- активные неисправности;
- запланированные обслуживания.

Такая структура позволяет масштабировать систему для компаний любого размера.

###  Система уведомлений

<p align="center">
  <img width="637" height="503" alt="image" src="https://github.com/user-attachments/assets/125bd28f-0e1d-4c4f-ad39-b8cac8c324d6" />
</p>

Сервис автоматически уведомляет пользователей о важных событиях.

Уведомления создаются при:

- появлении критической неисправности;
- наступлении срока обслуживания;
- просрочке ТО;
- завершении технического обслуживания;
- изменении состояния оборудования.

Особенности:

- типизированные шаблоны уведомлений;
- асинхронная доставка через **RabbitMQ**;
- автоматические напоминание о предстоящем ТО.
